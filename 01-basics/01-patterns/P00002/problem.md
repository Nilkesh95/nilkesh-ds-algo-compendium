## Problem Statement

Given a positive integer `n`, print a right-angled triangle pattern consisting of `n` rows.

Each row should contain asterisks (`*`), with the number of asterisks increasing by one in each successive row.

## Input

A single positive integer `n`, representing the number of rows.

## Output

Print `n` rows, where the `i`-th row contains exactly `i` asterisks.

## Examples

### Example 1

**Input:**
```text
n = 4
```

**Output:**
```text
*
**
***
****
```

### Example 2

**Input:**
```text
n = 5
```

**Output:**
```text
*
**
***
****
*****
```

## Constraints:

1 <= n <= 100

## Problem Statement

Given a positive integer `n`, print a right-angled triangle pattern consisting of `n` rows.

Each row should contain numbers, with the count of numbers increasing by one in each successive row.

## Input

A single positive integer `n`, representing the number of rows.

## Output

Print `n` rows, where the `i`-th row contains exactly `i` numbers. The number to be printed should be the same as the `i`-th row.

## Examples

### Example 1

**Input:**
```text
n = 4
```

**Output:**
```text
1
22
333
4444
```

### Example 2

**Input:**
```text
n = 5
```

**Output:**
```text
1
22
333
4444
55555
```

## Constraints:

1 <= n <= 100

## Problem Statement

Given a positive integer `n`, print a solid square pattern consisting of `n` rows and `n` columns.

Each position in the solid square should contain an asterisk (`*`).

## Input

A single positive integer `n`, representing the number of rows and columns.

## Output

Print `n` rows, each containing exactly `n` asterisks.

## Examples

### Example 1

Input: n = 4

Output:
`
****
****
****
****
`

### Example 2

Input: n = 5

Output:
`
******
******
******
******
******
`

## Constraints:

1 <= n <= 100

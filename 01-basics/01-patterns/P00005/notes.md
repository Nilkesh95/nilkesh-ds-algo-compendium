
## Approach

Here we have to observe that the col loop is working (n-row) times for every value of row.<br>
For example, for n=5:<br>
When row=0, col takes the values from 0 to n-row, n-row = 5 - 0 so col goes from 0 to 4<br>
When row=1, col takes the values from 0 to n-row, n-row = 5 - 1 so col goes from 0 to 3<br>
When row=0, col takes the values from 0 to n-row, n-row = 5 - 2 so col goes from 0 to 2<br>
and so on...
